## 5. El hallazgo — el free-lunch del exploratorio no sobrevive la cartera real + CSCV

El barrido exploratorio (2026-07-22) declaró subir el TP "monótono, DD-neutral y robusto" con **capital
ilimitado, entradas neutras y trades independientes**. Este harness agrega las dos cosas que faltaban —
**capital finito + `max_positions=5`** y **entradas del engine real** — y ahí aparece lo que el
exploratorio no podía ver:

- **La correlación diaria baseline↔candidato es 0.978, pero el 98.9% de los trades comunes tienen salida
  distinta** (y `n_taken` cae 1337→1268). Con slots finitos, **una sola salida distinta libera un slot en
  otro momento → cascada** que cambia qué entradas se toman después. Los brazos **no** son casi-idénticos:
  el cambio de TP induce **divergencia de path real** en toda la cartera.
- Sobre esa divergencia, **`PBO = 0.889`**: en el test combinatorio IS/OOS (CSCV), el brazo que mejor
  rankea in-sample **no** generaliza out-of-sample. El edge de +1.25pp existe en la curva **completa** de
  10y (por eso `DSR = 0.997`), pero **no es estable entre sub-períodos** una vez que se contabiliza la
  cascada de slots. DSR y PBO discrepan justamente porque miden cosas distintas: DSR pregunta "¿el Sharpe
  elegido supera al máximo esperado bajo el nulo, dados N intentos?" (sí, en el agregado); PBO pregunta
  "¿el mejor in-sample sigue siendo bueno out-of-sample?" (no).

**Lectura:** para un **refinamiento** cuya tesis era "chico pero gratis", un PBO de 0.889 es una bandera
roja legítima — el edge agregado es demasiado frágil out-of-sample para bancarlo. El anti-overfit gate
hizo su trabajo: atrapó la inestabilidad de sub-período que las métricas de período completo (CAGR/Sharpe/
DD) y el DSR no muestran. Es la misma disciplina de T7/T-CAT-6: si el criterio congelado no se cumple, no
se shipea aunque el estimador puntual seduzca.

## 6. Caveat honesto sobre el criterio (limitación, no override)

Hay una limitación declarable del propio kill-criteria: **PBO/CSCV está pensado para elegir entre muchas
configuraciones divergentes** (decenas), y acá se aplicó a **3 brazos colineales** (mismo universo, misma
estrategia, solo cambia el TP). Con 3 brazos el estimador CSCV es **grueso y de alta varianza**, y su
lectura es menos nítida que con una grilla ancha (limitación análoga a la mis-especificación "puntos vs
CAGR" de la lápida R2/T8, documentada post-hoc). **Esto NO cambia el veredicto** —el criterio estaba
congelado y no se cumplió (regla 2, no se re-decide después de ver el resultado)—, pero sí orienta el
follow-up: el test correcto para un refinamiento de un parámetro no es un ranking multi-config, sino una
comparación **pareada** baseline-vs-candidato.
